# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this project, please report it responsibly:

- **Email**: Do not use public issues for sensitive security reports. Please create a private security advisory on GitHub instead (Security > Report a vulnerability).
- Alternatively, contact via GitHub profile: [@twojlogin](https://github.com/twojlogin).

## Supported Versions

Only the latest commit on the default branch is actively supported.

## Guidelines

- Do not publicly disclose vulnerabilities before a fix is available.
- Provide a clear description, reproduction steps, and impact if possible.

Thank you for helping keep this project secure.
